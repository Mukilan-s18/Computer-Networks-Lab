# Experiment 04: Setup and Configure a LAN

## Objective
Set up and configure a Local Area Network (LAN) using a Switch and Ethernet cables.

## Instructions
1. **Physical Setup**: Connect 4 host machines to a central Switch using Ethernet cables.
2. **IP Configuration**:
   - Go to Network Settings on each PC.
   - Assign static IP addresses on the same subnet (e.g., `192.168.1.1` through `192.168.1.4`, Subnet Mask `255.255.255.0`).
3. **Connectivity Testing**:
   - Open Command Prompt.
   - Ping the other machines (e.g., `ping 192.168.1.2`).
4. **File Sharing**:
   - Create a folder on PC1.
   - Right-click -> Properties -> Sharing -> Share with everyone on the LAN.
   - Access the shared folder from PC2.
