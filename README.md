# Computer Networks Laboratory

This repository contains all 15 experiments for the Computer Networks Laboratory course. It demonstrates theoretical concepts, simulation-based designs, and code-based implementations of networking protocols.

## Structure
Each experiment is contained within its own dedicated folder, complete with instructions, code, generated datasets, and execution outputs.

1. **Experiment 01**: Study of various Network commands
2. **Experiment 02**: Study of Network cables
3. **Experiment 03**: CISCO Packet Tracer Basics
4. **Experiment 04**: Setup and configure a LAN
5. **Experiment 05**: Packet capture with Wireshark
6. **Experiment 06**: Error Correction using Hamming Code
7. **Experiment 07**: Flow control using Sliding Window Protocol
8. **Experiment 08**: Discover Live Hosts using NMAP
9. **Experiment 09**: Implementation of Subnetting
10. **Experiment 10**: Internetworking with Routers & DHCP
11. **Experiment 11**: Static & Dynamic Routing
12. **Experiment 12**: Transport Layer Client-Server
13. **Experiment 13**: Custom Ping Implementation
14. **Experiment 14**: Raw Sockets Packet Sniffer
15. **Experiment 15**: Web Log Analysis with Webalizer

## Setup & Execution
- Python 3 is required for experiments 6, 7, 12, 13, 14.
- Simulation experiments require Cisco Packet Tracer and Wireshark.
