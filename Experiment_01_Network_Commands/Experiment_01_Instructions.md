# Experiment 1: Study of Various Network Commands

## Objective
To study and understand the usage of various network commands in Windows and Linux environments.

## Commands Studied
1. **arp**: Displays and modifies the IP-to-Physical address translation tables used by ARP.
2. **hostname**: Displays the name of the current host.
3. **ipconfig /all** (Windows): Displays all current TCP/IP network configuration values.
4. **nbtstat**: Displays NetBIOS over TCP/IP (NetBT) protocol statistics.
5. **netstat**: Displays active TCP connections, ports on which the computer is listening, etc.
6. **nslookup**: Queries the Domain Name System (DNS) to obtain domain name or IP address mapping.
7. **pathping**: Combines features of ping and tracert.
8. **ping**: Verifies IP-level connectivity to another TCP/IP computer by sending ICMP Echo Request messages.
9. **route**: Displays and modifies the entries in the local IP routing table.
10. **ip** (Linux): Show / manipulate routing, network devices, interfaces, and tunnels.
11. **mtr** (Linux): Network diagnostic tool that combines `ping` and `traceroute`.
12. **tcpdump**: Command-line packet analyzer.

## Observation
These tools are essential for network troubleshooting, discovering connectivity issues, checking routing tables, and monitoring network traffic.
